# Oleksandr Dmytruk — Junior Full-Stack Developer

A responsive portfolio built with React, TypeScript, Vite, Tailwind CSS, and Lucide React.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` and `npm run lint` to verify changes.

## Customize

Edit personal details, portfolio copy, skills, education, work experience, and projects in [`src/data/portfolio.ts`](./src/data/portfolio.ts).

See [`PORTFOLIO_SETUP.md`](./PORTFOLIO_SETUP.md) for field guidance, screenshot and CV setup, technology verification notes, and the pre-publication checklist.

The contact form currently validates fields in the browser but does not send or store submissions.
